# PowerShell Scripts

This directory is reserved for future lab automation. This documentation update adds no configuration-changing scripts.

## Script standards

- Use descriptive names, comment-based help, parameters, and clear output.
- Make read-only checks the default; require explicit inputs for changes.
- Validate prerequisites and handle errors with useful messages.
- Never embed passwords, tokens, keys, or environment-specific secrets.
- Document required privileges, supported OS, expected effects, and safe verification or rollback.
- Test only in the isolated lab and record version, date, and results. Review every script before running it.
